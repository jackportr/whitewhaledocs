The WhiteWhale MCP connects Claude, ChatGPT, or any MCP-compatible tool directly to your WhiteWhale account. Once connected, the AI can see all your account data, signals, and scores — and you can work with it in plain English.

<Info>
  **MCP stands for Model Context Protocol.** It's a way to give AI tools access to your data. The WhiteWhale MCP is a wrapper over the API — when connected, the AI sees every API route as a tool it can use. You don't need to understand how it works. Just connect and start asking questions.
</Info>

## What you can ask

Once connected, ask anything about your WhiteWhale data:

- _"Which accounts should I reach out to today?"_
- _"Add these 20 companies to my list: \[paste domains\]"_
- _"What signals am I tracking and are they configured well?"_
- _"How many account credits do I have left?"_
- _"Find me new target accounts that match my ICP"_

The AI pulls your live WhiteWhale data and responds in plain English — no dashboards, no exports, no copy-pasting.

## Setup: Claude Connector

This is the fastest way to connect — no downloads, no config files, no terminal.

<Steps>
  <Step title="Open Claude and go to Connectors">
    In Claude, go to **Settings** → **Connectors** → **Custom Connectors**.
  </Step>
  <Step title="Add the WhiteWhale connector">
    Paste this URL:

    ```text
    https://app.getwhitewhale.com/mcp
    ```

    Press **Connect**. Claude will prompt you to log in to your WhiteWhale account and authorize the connection via OAuth. No API key needed — authentication is handled automatically.
  </Step>
  <Step title="Start a new chat">
    Open a new chat and ask WhiteWhale anything. Example:

    ```text
    Pull my best 5 accounts from WhiteWhale for [YOUR COMPANY].
    I want to know exactly why they are good for what I sell.
    ```
  </Step>
  <Step title="You're connected">
    Claude will respond with your actual WhiteWhale data. From here, keep asking questions — "Show me signals on \[company\]", "What's my score on \[account\]", "Add these domains to my list."
  </Step>
</Steps>

## Setup: MCP (ChatGPT, Claude Desktop, other tools)

For any MCP-compatible tool, the connection uses the same endpoint and OAuth flow.

**MCP URL:**

```text
https://app.getwhitewhale.com/mcp
```

<Steps>
  <Step title="Open your AI tool's MCP settings">
    - **ChatGPT:** Settings → Plugins → Developer Mode → Add Plugin → Input MCP url below.
    - **Claude Desktop:** Settings → Connectors → Add Custom Connector → Input MCP url below.
    - **Other tools:** Look for MCP, Plugins, or Integrations in settings
  </Step>
  <Step title="Add the WhiteWhale MCP URL">
    Paste `https://app.getwhitewhale.com/mcp` as the server URL.
  </Step>
  <Step title="Authorize with OAuth">
    You'll be prompted to log in to your WhiteWhale account and authorize the connection. No API key or user email needed — authentication is handled automatically through OAuth.
  </Step>
  <Step title="Start a new chat and ask a question">
    The AI now has access to all WhiteWhale API routes as tools. Try: _"Pull my top 5 accounts from WhiteWhale"_
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Claude says it can't connect to WhiteWhale">
    Make sure the connector URL is exactly `https://app.getwhitewhale.com/mcp` with no extra spaces or trailing slashes. Try removing and re-adding the connector, then start a fresh chat.
  </Accordion>

  <Accordion title="Authentication failed">
    The MCP uses OAuth — you should be prompted to log in to WhiteWhale when connecting. If the login prompt doesn't appear, try disconnecting the connector in Claude's settings and reconnecting.
  </Accordion>

  <Accordion title="Claude isn't seeing my accounts or signals">
    Start a new chat after connecting. Connector changes don't always take effect in an existing conversation. If it still doesn't work, verify your WhiteWhale account has active accounts and signals.
  </Accordion>
</AccordionGroup>
